You-AI-You is a simple set of instructions for your AI assistant. You bring the facts, the AI drafts within them, and you check and approve. No made-up details. No generic writing.

Three steps. You at both ends.

The AI works in the middle. You own the start and the finish.

1

You first

You share the facts, your goal, your audience and your limits. The AI asks questions before writing anything. Rough notes are fine.

2

AI second

The AI drafts using only what you gave it. It offers options, critiques its own draft and lists what you should check.

3

You last

You check every part. Is it true? Is it mine? Can I explain it? Nothing is final until you say so.

Install in a few minutes

Menu names change from time to time. If a button looks a little different, pick the closest match.

  1. Go to Settings → Capabilities and turn on Code execution and file creation (sometimes called Create and edit files).
  2. Go to Customize → Skills.
  3. Click +, then Create skill, then Upload a skill.
  4. Choose you-ai-you.zip.
  5. Make sure you-ai-you is switched on in your skills list.

On a Team or Enterprise plan, your organisation's owner may need to turn on skills first.

Option A: a Project (simplest)

  1. In the sidebar, click New project and name it "You-AI-You".
  2. Open the project's Instructions and paste this short line:
    Follow the You-AI-You method in the attached file you-ai-you.txt for every task in this project. Never skip a stage.
  3. Add you-ai-you.txt to the project's files.
  4. Start new chats inside this project.

Option B: a custom GPT (paid plans)

  1. Go to GPTs → Create, then the Configure tab.
  2. Name it "You-AI-You" and paste the short line above into Instructions.
  3. Under Knowledge, upload you-ai-you.txt.
  4. Click Create.

The full text is slightly longer than ChatGPT's instruction box allows, so the short line points it to the uploaded file.

  1. Go to gemini.google.com on a computer. Gems can only be created on the web.
  2. Click Gem manager in the sidebar, then New Gem.
  3. Name it "You-AI-You".
  4. In Instructions, paste everything from you-ai-you.txt. If it doesn't all fit, paste the short line from the ChatGPT tab.
  5. Under Knowledge, click Add files and upload you-ai-you.txt.
  6. Click Save.
  1. If your tool has custom instructions, projects or assistants (Copilot, Perplexity, DeepSeek, Grok and others), paste the contents of you-ai-you.txt there, or upload the file.
  2. If it doesn't, paste the whole text at the start of a new chat, then add:
    Use this method for the following task: …

Start using it

Just say what you want to make. The AI will ask you questions first.

"Let's use you-ai-you to write a cover letter for a marketing job."
"You-AI-You: help me reply to an unhappy customer."
"Use the You-AI-You method to plan a 1-hour lesson on budgeting."
Be specific"I trained 40 staff in 3 sessions" beats "I helped with training".
