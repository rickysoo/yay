# You-AI-You

**A simple way to work with any AI assistant so that the result is still yours.**

You-AI-You is a set of instructions you give to an AI assistant (Claude, ChatGPT, Gemini or similar). It makes the assistant work in three steps:

1. **You first.** You give the facts, your goal and your limits. The AI asks you questions before writing anything.
2. **AI second.** The AI drafts using only what you gave it. It offers options, points out weak spots and lists anything you should check.
3. **You last.** You check, edit and approve. Nothing is "done" until you say it is.

It works for emails, resumes, reports, lesson plans, presentations, decisions, data analysis, code and more. The AI won't make up facts, numbers or credentials to make your work look better.

## Step 1: Download the file you need

You don't need a GitHub account.

**To download a single file:**

1. On this page, click the file name (for example `you-ai-you.zip` or `you-ai-you.txt`).
2. On the next page, click the **Download** button (a small downward arrow near the top right of the file).
3. The file will be saved to your **Downloads** folder.

**To download everything at once:**

1. Near the top of this page, click the green **Code** button.
2. Click **Download ZIP**.
3. Open (unzip) the downloaded file. You'll find all the files inside.

## Step 2: Install it in your AI tool

Menu names change from time to time. If a button looks slightly different, look for the closest match.

### Claude (claude.ai or the Claude app)

Claude can install this as a **skill**, so it runs whenever you ask for it.

1. Go to **Settings → Capabilities** and make sure **Code execution and file creation** (sometimes called **Create and edit files**) is turned **on**.
2. Go to **Customize → Skills**.
3. Click **+**, then **Create skill**, then **Upload a skill**.
4. Choose the `you-ai-you.zip` file you downloaded.
5. Make sure the **you-ai-you** skill is switched **on** in your skills list.

On a Team or Enterprise plan, your organisation's owner may need to turn on skills first.

### ChatGPT

**Option A: a ChatGPT Project** (simplest)

1. In the left sidebar, click **New project** and name it "You-AI-You".
2. Open the project's **Instructions** (or project settings).
3. Open `you-ai-you.txt`, copy everything and paste it in. If it's too long to fit, paste this short version instead:
   > Follow the You-AI-You method in the attached file you-ai-you.txt for every task in this project. Never skip a stage.

   Then add `you-ai-you.txt` to the project's files.
4. Save. Start any new chat **inside this project**.

**Option B: a custom GPT** (needs a paid ChatGPT plan)

1. Go to **GPTs → Create**, then open the **Configure** tab.
2. Name it "You-AI-You".
3. In **Instructions**, paste the short version from Option A. The full text is slightly over the instruction length limit.
4. Under **Knowledge**, click **Upload files** and add `you-ai-you.txt`.
5. Click **Create** (or **Update**) and choose who can use it.

### Gemini

1. Go to [gemini.google.com](https://gemini.google.com) on a computer. Gems can only be created on the web.
2. Click **Gem manager** in the left sidebar, then **New Gem**.
3. Name it "You-AI-You".
4. In **Instructions**, paste everything from `you-ai-you.txt`. If it doesn't all fit, paste the short version from the ChatGPT section.
5. Under **Knowledge**, click **Add files** and upload `you-ai-you.txt`.
6. Click **Save**.

### Any other AI tool (Copilot, Perplexity, DeepSeek, Grok and others)

- **If it has a "custom instructions", "project" or "assistant" setting,** paste the contents of `you-ai-you.txt` there, or upload the file.
- **If it doesn't,** paste the whole text at the start of a new chat, followed by:
  > Use this method for the following task: …

## Step 3: Use it

Start a chat (in Claude, just mention the skill) and say what you want to make. For example:

- *"Let's use you-ai-you to write a cover letter for a marketing job."*
- *"You-AI-You: help me reply to an unhappy customer."*
- *"Use the You-AI-You method to plan a 1-hour lesson on budgeting."*

What happens next:

1. **The AI asks you questions** about the facts, your goal, your audience and your limits. Rough notes and bullet points are fine.
2. **It plays back a short brief.** Confirm it or correct it.
3. **It drafts**, often with options, a short self-critique and a "Check:" list of things to verify.
4. **You review it.** Is it true? Does it sound like me? Could I explain it if asked? Tell it what to change.
5. **It revises until you say it's final**, then gives you the clean version and a note on what came from you and what the AI helped with.

### Tips

- **Be specific.** "I trained 40 staff in 3 sessions" works far better than "I helped with training".
- **Push back.** If a line doesn't sound like you, say so, or rewrite it yourself.
- **The AI won't invent details.** If something is missing, it will ask you or leave a `[placeholder]`.
- **For anything important** (money, legal, health, published or signed work), have a person check it too.
